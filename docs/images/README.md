# Происхождение изображений

Все кадры получены из MatVision Studio с собственным демонстрационным принтом приложения. Генеративные концепты не используются как доказательство готовых функций.

- `studio-macro.png`: интерфейс установленной 0.1.5 при проверке фоторежима и макро.
- `corner-lift.png`, `layer-reveal.png`: демонстрационные деформации 0.1.4, сохранённые в 0.1.5. Они показывают заданные движения, не физический расчёт ткани.

Исходные PNG скопированы без ретуши. Материалы Poly Haven: см. [атрибуцию](../licenses/polyhaven-assets.md).
