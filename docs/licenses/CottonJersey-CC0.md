# Cotton Jersey — bundled PBR maps

Source: https://polyhaven.com/a/cotton_jersey
License: CC0 1.0 — https://polyhaven.com/license
Photographed by colormass; processed by Rico Cilliers.
Retrieved 2026-10-07. Source metadata gives a physical tile of 263.602747 × 263.799995 mm.

The application includes the original files (no image recoloring or baked lighting):

- `public/materials/cotton-jersey/nor_gl.jpg`: OpenGL normal, 4K.
- `public/materials/cotton-jersey/rough.jpg`: roughness, 2K.
- `public/materials/cotton-jersey/ao.jpg`: ambient occlusion, 2K.

MD5 values were checked against the official download metadata before use. Runtime loads only these bundled local assets; the application does not call Poly Haven or require internet access.

This is a generic real cotton jersey material. It is not a scan of a particular Gildan or Bella+Canvas garment.
