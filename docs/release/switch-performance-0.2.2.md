# MatVision Studio 0.2.2 — исправление зависания футболок

Дата: 2026-10-07. Исправление проверено на текущем компьютере Windows.

## Причина и изменение

При каждом выборе футболки приложение синхронно строило и уточняло сетку примерно из двух миллионов треугольников. Эта работа блокировала интерфейс на 28–29 секунд. Дополнительно создавались процедурные карты хлопка, которые сразу заменялись готовыми сканами.

Теперь геометрия готовится при сборке программы. Два локальных файла моделей загружаются и распаковываются асинхронно, а распакованные данные сохраняются в ограниченном кэше. Сетку основных панелей и подкладки сократили с помощью meshoptimizer; исходные позиции, нормали и UV сохранены. Внутренняя сторона соответствует упрощённым внешним панелям. Воротник, швы и подгибы сохранены без упрощения. Процедурная генерация футболок больше не входит в исполняемый код интерфейса.

## Проверки

- Сборка TypeScript, Vite и Windows Tauri 0.2.2 прошла.
- Выбор двух футболок, возврат к коврику и повторный выбор в EXE прошли без ошибок JavaScript.
- Ошибка загрузки модели сохраняет прежний товар; повторная попытка работает. Быстрые переключения не возвращают устаревшую футболку поверх нового товара.
- Отдельные принты спереди и сзади, незапечатанная внутренняя сторона и подготовка геометрии для режима «Фото» сохранены.
- Подготовлены 32 контрольных изображения футболок и кружки. Сравнение чистых футболок с принятым R10 даёт среднюю абсолютную разницу RGB 0.04–0.31 из 255; изображения кружки совпадают. Пиксельное сравнение является вспомогательным измерением.
- Субагент `/root/realism_reviewer` просмотрел все 24 кадра футболок, включая отдельные передние/задние принты и полости: Gildan сохраняет 9.1/10, Bella — 9.0/10. Новых видимых дефектов не обнаружено. Независимый отчёт: `realism-acceptance-0.2.2.md`. Оценка субъективная; неизменённая кружка сохраняет прежнюю оценку 9.0/10.

Полная регрессия и установка на чистую Windows не проводились. Изменение направлено на зависание при выборе товара.

## Сборка моделей

`scripts/build.mjs` запускает `scripts/bake-garments.mjs` до сборки интерфейса. Готовые модели и manifest находятся в `public/models/garments`. Расширение `.mvgz` позволяет приложению самостоятельно распаковывать gzip без автоматической распаковки HTTP-сервером. Исходная параметрическая геометрия остаётся в `src/geometry/garment.ts`; сборщик использует её для обновления локальных моделей.
