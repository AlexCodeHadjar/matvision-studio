# Руководство пользователя · 0.1.6

[К описанию проекта](../README.md)

## Установка и обновление

Скачайте `MatVisionStudio-0.1.6-x64-setup.exe` из [Releases](https://github.com/AlexCodeHadjar/matvision-studio/releases/tag/v0.1.6). Пока репозиторий приватный, войдите в GitHub-аккаунт с доступом. Сохраните открытый проект, закройте предыдущую версию и запустите установщик. Затем используйте ярлык MatVision Studio.

Нужны Windows 10/11 x64 и WebView2. Если WebView2 отсутствует, установщику понадобится интернет. Node.js и Rust для готовой программы не нужны. Выпуск не заявлен как подписанный сертификатом разработчика. Для обычной установки выбирайте файл с `setup`, а не отдельный EXE.

Для возврата к 0.1.4 сохраняйте копии старых проектов: новый формат v2 в ней не откроется.

## Изделие и рисунок

Вверху выберите Desk Mat 900 × 400 мм или Mouse Pad 400 × 450 мм. Нажмите «＋ Изображение» либо перетащите PNG/JPEG/WebP на сцену. SVG, PDF и PSD сначала нужно экспортировать в поддерживаемый растровый формат.

| Размещение | Результат |
| --- | --- |
| Cover / Заполнить | Сохраняет пропорции, заполняет коврик; часть рисунка обрезается |
| Contain / Вписать | Сохраняет рисунок целиком; возможны свободные поля |
| Stretch / Растянуть | Заполняет поверхность с изменением пропорций |

Настройте масштаб, сдвиг и поворот. Для перетаскивания рисунка по коврику включите редактирование клавишей `E`. Проверяйте логотипы и текст в ракурсе «Сверху». Effective DPI учитывает исходные пиксели и размер размещения, но не гарантирует качество печати.

## Материал, край и свои карты

Выберите ткань, шероховатость, толщину и обычный/прошитый край. «Применить ткань Poly Haven» загружает встроенные normal/roughness-карты; цветной узор исходного материала не используется, принт сохраняется.

В «Свой материал» отдельно для ткани и резины доступны карты цвета, нормалей, шероховатости и высоты. Форматы PNG/JPEG/WebP; максимум 8 МиБ и 16 мегапикселей на карту. Оригиналы включаются в проект, версия для GPU ограничивается стороной 2048 px.

Используйте бесшовные карты. Укажите физический размер повторения и направление Y нормалей (OpenGL/DirectX). Цвет ткани умножается на принт; белая карта сохраняет его окраску. Шероховатость читается из зелёного канала, высота — из красного; у обычных серых карт каналы должны совпадать. Высота влияет на освещение микрорельефа, но не меняет геометрический силуэт.

## Камера, освещение и движение

Левая кнопка вращает камеру, правая сдвигает, колесо приближает. Готовые ракурсы находятся в разделе «Камера»; «Макро ткани» показывает шов и рельеф. Выберите студийный свет и поверхность под ковриком. Сравнивайте материалы в одинаковых условиях.

Переключатель «Мягкий студийный свет» добавляет пять крупных источников света для интерактивной сцены. Это эксперимент: он выключен при запуске, не сохраняется в `.matvision` и не меняет освещение отдельного фоторежима. Если результат не подходит, выключите его: прежний вид сцены восстановится.

«Скрутить», «Раскрыть» и ползунок задают положение рулона. Восемь демонстраций временно меняют позу/камеру/свет, не изменяя сохранённые параметры. Это заданные движения, а не расчёт измеренной жёсткости изделия. Перед фото остановите сцену в нужной позе.

## Сохранение проекта и PNG

`Ctrl+S` сохраняет `.matvision`: принт, карты, изделие, размещение, камеру и настройки просмотра. Большой размер проекта с картами — ожидаемое следствие переносимости. Для переноса достаточно файла проекта. `Ctrl+Shift+O` открывает его снова.

При повреждённом файле или карте прежняя сцена должна сохраниться; не перезаписывайте оригинал при восстановлении.

`Ctrl+E` экспортирует сцену без интерфейса. Размер выбирается в разделе «Экспорт»: текущий viewport или длинная сторона 3840 px. Это экспорт интерактивного просмотра; физическое освещение рассчитывает отдельное «Фото».

## Фоторежим

1. Подготовьте материалы, камеру и позу, нажмите «Фото».
2. Выберите HDR-фотостудию Poly Haven либо текущую студийную схему.
3. Укажите 1920/2560/3840 px и 128/512/1024 прохода. По умолчанию 1920/512.
4. Нажмите «Рассчитать фото». Сначала готовятся геометрия, материалы и шейдеры, затем уточняется свет. Первый кадр может потребовать ожидания.
5. После полного прохода можно остановить расчёт и сохранить текущий результат. Больше проходов обычно уменьшает шум. Шумоподавления пока нет.
6. «Сохранить фото PNG» открывает системный диалог. «Вернуться в студию» восстанавливает управление; во время расчёта доступна отмена.

Фото фиксирует позу и ракурс на момент запуска. Его размер, число проходов и отдельное освещение пока не сохраняются в проекте.

## Горячие клавиши

| Действие | Клавиши |
| --- | --- |
| Открыть изображение / проект | `Ctrl+O` / `Ctrl+Shift+O` |
| Сохранить проект / обычный PNG | `Ctrl+S` / `Ctrl+E` |
| Редактировать принт | `E` |
| Сброс камеры / сверху / перспектива | `R` / `1` / `2` |
| Скрыть панели / справка | `H` / `F1` |
| Фокус / закрыть окно настроек | `Tab` / `Escape` |

## Если что-то не работает

| Симптом | Что проверить |
| --- | --- |
| Ограничение Intel UHD в фото | В настройках графики Windows выберите мощную видеокарту для MatVision и перезапустите. Проверена RTX 3050 Laptop; остальные GPU требуют проверки |
| Долгая подготовка первого кадра | Это может быть компиляция сложного шейдера. Дождитесь результата или отмените. При повторяемой ошибке сохраните её текст и модель GPU |
| Зернистое фото | Увеличьте число проходов; denoiser ещё не добавлен |
| Крупное переплетение / перевёрнутый рельеф | Проверьте физический размер повторения, normal Y и силу рельефа |
| Принт темнее исходника | Свет, окраска ткани и ACES влияют на вид. Измеренная ICC-цветопроба пока отсутствует |
| Проект не открывается в 0.1.4 | Формату v2 нужна 0.1.5; сохраняйте старые файлы для возврата |

Для сообщения об ошибке укажите версию, Windows, GPU, последовательность действий, размер фото и число проходов. Прилагайте минимальный пример без конфиденциального принта. [Создать issue](https://github.com/AlexCodeHadjar/matvision-studio/issues/new/choose).
