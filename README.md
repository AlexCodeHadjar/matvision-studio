# MatVision Studio

Приложение Windows для просмотра принта на ковриках, футболках и кружках в реальном времени.
Версия 0.3.0: добавлены худи, свитшоты, сумки-шопперы, лонгсливы, поло, бейсболки и фартуки.
Кружка переработана по образцу, особенно тонкая овальная ручка и плавные соединения с корпусом.
Подготовленные модели загружаются асинхронно. Объёмные полые футболки, открытые рукава и горловина, скан хлопкового трикотажа,
независимые принты спереди/сзади и гладкая керамическая кружка 11 oz. Ограничения печати и источники:
[PRODUCT_PRINTING.md](docs/PRODUCT_PRINTING.md).
Новые категории и их зоны описаны в [CATALOG.md](docs/CATALOG.md).
Tauri 2, React, strict TypeScript и Three.js/WebGL2. Геометрия задана в метрах SI:
Desk Mat **900 × 400 мм** и Mouse Pad **400 × 450 мм**.

## Использование

1. Запустите MatVisionStudio.exe из папки выпуска или ярлык MatVision Studio на рабочем столе.
2. Перетащите PNG, JPEG или WebP из проводника в центральную сцену. Можно также нажать
   «Открыть изображение». По умолчанию Cover заполняет коврик с сохранением пропорций.
3. Выберите продукт. Contain показывает весь рисунок; Stretch явно растягивает его
   по размеру поверхности. Масштаб, сдвиг и поворот доступны в панели Print Layout.
4. Включите Edit Print, чтобы двигать изображение прямо по поверхности. Камера,
   шесть ракурсов, включая «Макро ткани», Turntable и линейка помогают рассмотреть размер, ткань и толщину.
   В разделе «Материал и свет» откройте «Поверхность под ковриком»: нейтральная студия,
   белый стол, матовый графит, светлый дуб, тёмный орех или светлый бетон. Небольшая
   мягкая тень включена автоматически. Выбранная поверхность видна и в экспорте PNG.
   В разделе «Анимация коврика» доступны «Скрутить», «Раскрыть» и «Пауза».
   Ползунок «Скручивание» задаёт положение от 0% (разложен) до 100% (рулон).
   Во время движения можно вращать камеру; выбранное положение сохраняется в проекте.
   Ниже находятся восемь временных демонстраций: подъём уголка, мягкая волна,
   укладка на стол, переворот, скручивание с двух сторон, облёт оверлока,
   движущийся свет и показ слоёв. Они возвращают сцену в исходное состояние и
   не изменяют сохранённые параметры проекта. Подробности: [анимации](ANIMATIONS.md).
5. В разделе «Реализм» выберите быстрый или детальный режим, настройте переплетение, рельеф и блеск. При необходимости загрузите свои карты ткани и резины. [Возможности и ограничения 0.1.5](REALISM.md).
6. Сохраните проект через Ctrl+S. Файл `.matvision` версии 2 содержит исходное изображение и карты материалов,
   размещение, материал, свет, поверхность под ковриком, камеру и настройки просмотра; исходный файл можно
   переместить после сохранения проекта.
7. Кнопка «Фото» рассчитывает физическое освещение: выберите HDR-фотостудию, размер и число проходов, дождитесь результата и сохраните PNG. Подготовка первого кадра может занять время.
8. Экспортируйте PNG через Ctrl+E: Screen сохраняет размер viewport, High Resolution
   рендерит изображение с длинной стороной 3840 px. Панели интерфейса в PNG не попадают.

Три тканевых материала, четыре варианта освещения, регулируемая толщина и шероховатость,
резиновая нижняя сторона и Standard Cut / Stitched Edge работают в настоящей 3D-сцене.
Исходные пиксели используются для оценки effective DPI; ограниченный GPU-preview не
уменьшает эту оценку. Низкое разрешение сопровождается пояснением, но не запрещает импорт.

## Управление

| Действие                             | Мышь / клавиши                 |
| ------------------------------------ | ------------------------------ |
| Вращение камеры                      | Левая кнопка + перетаскивание  |
| Сдвиг камеры                         | Правая кнопка + перетаскивание |
| Приближение                          | Колесо                         |
| Перемещение принта                   | Edit Print + левая кнопка      |
| Масштаб принта                       | Ctrl + колесо в Edit Print     |
| Открыть изображение / проект         | Ctrl+O / Ctrl+Shift+O          |
| Сохранить проект / экспорт PNG       | Ctrl+S / Ctrl+E                |
| Сброс камеры / сверху / перспектива  | R / 1 / 2                      |
| Edit Print / скрыть панели / справка | E / H / F1                     |

Tab перемещает клавиатурный фокус между элементами. Escape закрывает справку и настройки.

## Сборка разработчиком

Требования: Windows 10/11 x64, Node.js 24 LTS, pnpm 11.19.0, Rust с MSVC target,
Visual Studio C++ Build Tools, Windows SDK и Microsoft Edge WebView2 Runtime.
[Официальная подготовка Tauri](https://v2.tauri.app/start/prerequisites/) описывает установку
системных компонентов. На машине пользователя приложения Node.js и Rust не нужны.
Установщик загружает WebView2, если runtime отсутствует; для этого нужен интернет.

Из каталога репозитория выполните последовательно:

```powershell
pnpm install --frozen-lockfile
pnpm lint
pnpm typecheck
pnpm test
pnpm tauri dev
```

Для production-сборки:

```powershell
pnpm tauri build
```

EXE: `src-tauri/target/release/matvision-studio.exe`.
Windows installer: `src-tauri/target/release/bundle/nsis/`.
Все runtime-ресурсы сцены локальные; сервер Vite для установленного приложения не нужен.

На исходном development host использован проверенный локальный Rust/MSVC/SDK toolchain
вне репозитория. Здесь перед командами можно выполнить `. ./scripts/native-env.ps1`.
Этот необязательный helper не входит в зависимости приложения и не заменяет обычные
системные prerequisites на другом компьютере. Подробности: [native toolchain](docs/native-toolchain.md).

## Цвет и локальные данные

Studio Preview учитывает свет и материал. Print Proof требует измеренного ICC-профиля
принтера, чернил и ткани и пока недоступен. Ручной профиль материала хранит компенсацию
яркости, насыщенности, чёрного, оттенка поверхности, контраста и шероховатости вместе
с проектом. Его значения по умолчанию не являются измеренной калибровкой.

Изображения обрабатываются локально. Внешней telemetry нет. Приложение не исполняет
импортированные файлы; первый релиз принимает PNG/JPEG/WebP и отклоняет SVG.

Переключение товаров находится в разделе «Товар и зона печати». Модель заготовки выбирается сверху. У футболки доступны независимые стороны «Спереди» и «Сзади», цвет ткани и зона 300 × 380 мм. ## Запуск последней версии с рабочего стола (Windows)

Дважды щёлкните `install-desktop.cmd` в корне репозитория. Скрипт обновит ветку
`claude/inspiring-euler-mkaca2`, соберёт приложение, скопирует его в
`%LOCALAPPDATA%\MatVisionStudio\<версия>\MatVisionStudio.exe`, обновит ярлык
«MatVision Studio» на рабочем столе и запустит программу. Нужны Git, Node.js с pnpm,
Rust и Visual Studio Build Tools (C++); если рядом с репозиторием лежит прежний
локальный набор `work/toolchain`, используется он. Параметры: `-SkipUpdate` —
собрать текущее состояние без `git pull`, `-NoLaunch` — не запускать после сборки.
